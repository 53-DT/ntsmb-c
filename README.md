# DeckFiles UI milestone 1

This branch is intentionally a UI-only prototype. It recreates the Files browser and Add Media Source screens from the supplied reference images.

- App ID: `io.github.53dt.deckfiles`
- Version: `0.1.0`
- D-pad navigation: spatial focus with arrow keys; OK/Enter activates controls; Back/Escape closes the modal.
- No SMB, local filesystem, storage vault, or playback backend is connected in this milestone.

The GitHub Actions workflow packages `app/` into a webOS IPK and uploads it as an artifact.
